## 💻 Essential Linux Commands

### 1. Basic Commands

```bash
pwd
whoami
who
uname -a
date
clear
```

### 2. File Management

```bash
ls -la
mkdir myproject
cd myproject
touch file.txt
cp file.txt backup.txt
mv file.txt newfile.txt
rm newfile.txt
```

### 3. Permissions

```bash
ls -l
chmod 755 script.sh
sudo chown ec2-user:ec2-user script.sh
```

### 4. Process and System Monitoring

```bash
top
ps aux
free -h
df -h
uptime
```

### 5. Networking

```bash
ip addr
ping -c 4 8.8.8.8
curl -I https://example.com
ss -tuln
```
